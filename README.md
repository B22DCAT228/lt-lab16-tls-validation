# LAB16 - TLS Certificate Validation

Labtainers exercise for HTTPS and TLS certificate validation.

## Topology
- ext-client: 172.31.66.50
- tls-server: 172.31.66.40:8443

## Learning objectives
- Reject untrusted certificates and incorrect hostnames
- Verify trusted CA, SAN and SHA256 fingerprint
- Check TLS version and HTTPS response

Download imodule.tar from GitHub Releases and install with imodule.
